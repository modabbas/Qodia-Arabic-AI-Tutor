# Fix Dashboard "Today's Challenge" Card - Make It Dynamic

## The Bug (Critical)

On the main student dashboard (after login), there's a card titled "تحدّي اليوم / مفهوم 01" that currently shows HARDCODED content:

**Currently displayed (WRONG):**
- Title: "ليش اخترت CASCADE؟"
- Description: "من علاقة المريض بمواعيده إلى الدفاع عن قرارك في كود Django. خمس لمسات، على إيقاعك."

**The problem:**
- This user's project is "منصة إدارة مطار" with tech stack "Flutter"
- The card should show a Flutter-related concept, NOT a Django one
- The card must dynamically reflect the user's actual project

## What Needs to Happen

The "تحدّي اليوم" card on the dashboard should call the same Gemini generation logic that /session uses, but ONLY to display a preview (concept name + short description).

### Expected Behavior

For a **Flutter** student working on "منصة إدارة مطار":
- Title: "ليش استخدمت StatefulWidget؟" (or any Flutter concept)
- Description: "من إدارة حالة الرحلات في تطبيقك إلى الدفاع عن قرارك التقني. خمس لمسات مصممة لك."

For a **React** student working on "متجر إلكتروني":
- Title: "متى تستخدم useEffect؟" (or any React concept)
- Description: "من إدارة عربة التسوق في متجرك إلى شرح قرارك للجنة. خمس لمسات على مقاسك."

## Implementation Plan

### Option A (Preferred): Reuse Existing Session API

The `/api/generate-session` endpoint already generates full sessions with concept names. We just need to display a preview of the cached session on the dashboard.

**Steps:**
1. On dashboard mount, call `/api/generate-session` (returns cached session for today)
2. Extract from response: `concept_name_ar` and `concept_intro`
3. Display in the "تحدّي اليوم" card
4. Keep the existing "ابدأ جلسة اليوم" button linked to `/session`

### Option B: Create Lightweight Preview API

If Option A is expensive (loading full session), create a lightweight endpoint:
- `/api/session-preview` — returns only `{ concept_name_ar, concept_intro }`
- Uses same cache as `/api/generate-session`
- Much faster to load
