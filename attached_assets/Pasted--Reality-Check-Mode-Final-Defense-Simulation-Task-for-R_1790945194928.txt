# Reality Check Mode - Final Defense Simulation

## Task for Replit Agent

**IMPORTANT: Enable Extended Thinking (🧠)**

Build Qodia's crown feature: `/final-defense` — a stress-tested simulation of a real graduation project defense committee.

## The Vision

After a student completes their 30-concept learning journey, they face **the ultimate test**: a 5-question defense simulation with 3 virtual professors. This proves whether they're truly ready for their real defense.

**For the student:** The moment of truth
**For the judges:** The feature that proves Qodia delivers on its promise

## Prerequisites (Must Already Exist)

- ✅ Learning Path Engine (concepts with mastery scores)
- ✅ Cumulative Project (student's accumulated code files)
- ✅ Code Validation (3-level system)
- ✅ Progressive Hints
- ✅ Session completion tracking

These are already built. This feature USES them, doesn't rebuild them.

## Technical Implementation

### Database Schema

**New table: `defense_simulations`**
```typescript
{
  id: uuid,
  user_id: string,
  started_at: timestamp,
  completed_at: timestamp,
  overall_score: number (0-100),
  questions: [
    {
      question_number: number,
      professor: string,
      question_text: string,
      concept_tested: string,
      student_answer: string,
      score: number,
      time_used: number,
      feedback: string
    }
  ],
  final_verdict: string,
  weak_concepts: string[]
}
```

### API Routes

**POST `/api/defense/start`**
- Checks if student eligible (10+ concepts)
- Calls Gemini to generate 5 questions
- Creates defense_simulation record
- Returns questions

**POST `/api/defense/submit-answer`**
- Takes question_id + answer + time_used
- Calls Gemini for evaluation
- Updates defense_simulation record
- Returns feedback + score

**POST `/api/defense/complete`**
- Calculates overall score
- Generates final verdict
- Returns full report

### Timer Behavior

- Shows large countdown in top-right
- Changes color at thresholds:
  - 60-30s: Green
  - 29-15s: Amber
  - 14-0s: Red (gentle pulse)
- Auto-submits when timer hits 0
- Does NOT penalize for using full time

## Edge Cases

**1. Student has only 10 concepts:**
- Allow entry but show warning: "موصى بإكمال ٢٠+ مفهوم أولاً"

**2. Internet drops mid-defense:**
- Save progress every answer
- On reconnect: "تريد إكمال المحاكاة؟"

**3. Student quits early:**
- Save partial result
- Allow restart (new questions)

**4. Gemini fails:**
- Fallback to curated question bank (store 20 generic questions per tech stack)

## What NOT to Do

- Do NOT allow re-answering (realistic defense = no re-takes)
- Do NOT show hints during defense (tests real knowledge)
- Do NOT modify: Learning Path, Cumulative Project, Validation, Hints
- Do NOT change existing dashboards drastically

## Success Criteria

The feature works when:
1. Student completes real defense simulation feeling the pressure
2. Questions are specific to their actual project files
3. Evaluation feels fair and educational
4. Judges see "this is a real preparation tool"
