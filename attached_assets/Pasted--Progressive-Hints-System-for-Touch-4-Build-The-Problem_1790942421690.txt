# Progressive Hints System for Touch 4 (Build)

## The Problem

Students reach Touch 4 (Build) without knowing the exact syntax to write. For example:
- Task: Add dependencies in `pubspec.yaml`
- Student doesn't know YAML syntax
- Student doesn't know Flutter conventions
- Result: student stuck or guesses randomly

The explanation in Touch 2 (Reveal) is too abstract. Students need **progressive guidance** in Touch 4 itself.

## The Solution: 3-Tier Progressive Hints

Add a "تلميح" (Hint) button to Touch 4. When clicked, it reveals progressively more help:

- **Hint 1** (after 1st attempt): General guidance - direction without syntax
- **Hint 2** (after 2nd attempt): Similar example - shows syntax of RELATED thing
- **Hint 3** (after 3rd attempt): Partial solution - shows most of the answer

Each hint used = -10 XP from final score. Keeps challenge, prevents cheating.

### 3. Attempt + Hint Tracking Logic

```typescript
interface TouchAttemptState {
  attempts: number;        // Submissions made
  hintsUsed: number;        // 0, 1, 2, or 3
  xpPenalty: number;        // 0, 10, 20, or 30
}

function canUnlockNextHint(state: TouchAttemptState): boolean {
  // Hint 1: available after 1st failed attempt (or always available)
  // Hint 2: available after 2nd failed attempt AND hint 1 used
  // Hint 3: available after 3rd failed attempt AND hint 2 used
  
  if (state.hintsUsed === 0 && state.attempts >= 1) return true;
  if (state.hintsUsed === 1 && state.attempts >= 2) return true;
  if (state.hintsUsed === 2 && state.attempts >= 3) return true;
  return false;
}

function getHintButtonState(state: TouchAttemptState): string {
  if (state.hintsUsed === 0 && state.attempts === 0) {
    return "disabled"; // Encourage trying first
    // OR: "available" with text "💡 تلميح (مجاناً للمحاولة الأولى)"
  }
  
  if (canUnlockNextHint(state)) {
    return `available-hint-${state.hintsUsed + 1}`;
  }
  
  if (state.hintsUsed === 3) {
    return "exhausted"; // All used
  }
  
  return "locked"; // Need more attempts
}
```

### 4. Smart Button Behavior

**Before first attempt:**
- Button is subtle gray with text: "💡 جرّب أولاً"
- Clicking shows: "جرّب كتابة الكود أولاً، التلميح بيصير متاح بعد المحاولة"

**After 1 failed attempt:**
- Button becomes active green: "💡 تلميح 1/3"
- Pulsing animation to attract attention

**After hint used + another failed attempt:**
- Button shows: "💡 تلميح 2/3 (-10 XP)"
- Still active

**After all 3 hints used:**
- Button becomes: "📖 عرض الحل النموذجي"
- Click shows reference answer, student can learn and retry (-50 XP total)

### 5. Edge Case: Student Nails It First Try

If student submits correct code on first attempt:
- +50 XP bonus for "First Try Hero!"
- Celebration animation
- No hints shown or offered

## Critical Requirements

1. **Preserve existing Touch 4 UI** - just add hint system
2. **Gemini generates hints** - don't hardcode (each concept needs its own hints)
3. **Hints must be helpful, not condescending** - teacher tone, not professor tone
4. **XP penalty is cumulative but capped** - max -30 XP from hints, additional -20 if "show solution"
5. **Progress bar in Touch 4** - show "محاولة X - تلميحات مستخدمة Y"

## What NOT to Do

- Do NOT show all 3 hints at once
- Do NOT allow unlimited hints
- Do NOT give full solution in Hint 1
- Do NOT remove validation (hints + validation work together)
- Do NOT modify other touches or pages
