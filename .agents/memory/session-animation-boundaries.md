---
name: Session animation boundaries
description: Reward honesty and stable interaction targets when adding lesson animations.
---

Visual polish must not invent persisted XP. Typing feedback is practice-only unless the reward contract is deliberately changed.

**Why:** The session-motion brief used illustrative reward amounts while requiring existing learning and project persistence to remain unchanged. Applying those examples as real earnings would misrepresent saved progress.

**How to apply:** Keep completion rewards authoritative from the server and distinguish practice feedback from saved XP. A request to change the reward system needs a separate, explicit implementation decision.

Continuous card motion should animate a decorative surface, not the controls or their bounding boxes.

**Why:** Moving an entire card continuously prevented ordinary browser-test clicks from finding stable targets. Floating only the decorative surface retained the requested effect while allowing normal clicks.

**How to apply:** Keep buttons and editor controls stationary during ambient loops. Brief entrance, hover, and answer-feedback animations are still appropriate.
