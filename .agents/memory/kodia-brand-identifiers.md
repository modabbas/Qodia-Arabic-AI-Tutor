---
name: Kodia brand identifiers
description: Why the new public name differs from existing technical identifiers.
---

Use **كوديا** for public Arabic branding and **KODIA/Kodia** for public English branding, but retain existing Qodia-named package, route, cookie, and token identifiers unless a separately planned compatibility migration is needed.

**Why:** The public name changed from قُوديا/QODIA. Renaming session identifiers or package paths as part of a visual rename could sign users out or break application routing and stored integrations.

**How to apply:** New public copy and downloadable filenames use Kodia. Avoid changing persistent identifiers merely to eliminate old naming from internal code.
