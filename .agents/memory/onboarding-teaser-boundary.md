---
name: Onboarding teaser boundary
description: Product intent for the tech-specific first-challenge preview during project setup.
---

The onboarding first-challenge card is a static, tech-specific teaser that updates immediately with the selected stack. It is not a promise that the displayed concept is the actual generated first lesson.

**Why:** The user explicitly prefers an instant, free preview with no Gemini call and no changes to actual session generation or onboarding submission.

**How to apply:** Keep neutral copy for empty or unsupported selections, cover supported stacks with static examples, and distinguish the teaser from the personalized lesson. Do not introduce lesson-generation requests just to populate this card.
