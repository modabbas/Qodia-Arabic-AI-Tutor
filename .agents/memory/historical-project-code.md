---
name: Historical project code
description: How to represent lessons completed before Qodia began saving student-written project code.
---

Earlier lessons may have concepts and XP but no saved Touch 4 code. Show their concepts as learned history and leave the corresponding project files planned; never label missing, inferred, or AI-generated code as student-built completion.

**Why:** The user explicitly chose this treatment because the earlier code was not stored. Marking files complete without their actual code would misrepresent the student's work.

**How to apply:** Use this rule for existing-account backfills, project progress counts, file viewers, and any future exports or readiness claims.
